# Custom Bookmark Sidebar

Chrome のサイドパネルに、カスタムアイコン付きのブックマークを並べる拡張機能。キーボードショートカットで、サイドパネルを開かなくてもブックマークを開ける。
ブラウザ「Sidekick」（2025年8月にサービス終了）の左端アプリドックを、Chrome 拡張の範囲で模したもの。

## 主な機能

- **サイドパネル表示**: アイコンをパネル幅に合わせて格子状に並べる。ツールバーアイコンかショートカットで開閉
- **カスタムアイコン登録**: PNG/JPEG（最大 300KB）
- **最大 12 件のブックマーク登録**（重複 URL 不可）
- **ドラッグ&ドロップで並び替え**
- **右クリックで削除**（パネル内で確認）
- **キーボードショートカット**: Chrome の拡張機能コマンドとして登録するので、Google Docs などページ側のショートカットに妨げられない
- 同じサイト（オリジン）のタブが開いていれば、新しく開かずにそのタブへ移動する

## キーボードショートカット

| ショートカット（Mac は Control キー） | 動作 |
|---|---|
| `Ctrl+Shift+A` | サイドパネルを開閉 |
| `Ctrl+Shift+S` | ブックマーク 1 番目を開く |
| `Ctrl+Shift+D` | ブックマーク 2 番目を開く |
| `Ctrl+Shift+F` | ブックマーク 3 番目を開く |
| （手動設定。推奨 `Ctrl+Shift+G`） | ブックマーク 4 番目を開く |
| （手動設定） | ブックマーク 5 番目を開く |

> Chrome では、拡張機能が初期値として指定できるショートカットは 4 つまでです。4・5 番目は `chrome://extensions/shortcuts` で設定してください。
> 設定したショートカットは、アイコンにマウスを重ねたときの説明に表示されます。

## インストール（開発版）

1. このリポジトリをクローンまたはダウンロード
2. Chrome で `chrome://extensions/` にアクセス
3. 右上の「デベロッパーモード」を有効化
4. 「パッケージ化されていない拡張機能を読み込む」で本フォルダを選択
5. ツールバーの拡張機能アイコン（またはショートカット）でサイドパネルを開く

サイドパネルを左右どちらに出すかは、Chrome の設定（デザイン → サイドパネルの位置）で選びます。拡張機能からは指定できません。

## ブックマークの追加方法

1. サイドパネル下部の「＋」ボタンをクリック
2. アイコン画像（PNG/JPEG、300KB 以下）をドロップまたはファイル選択
3. URL を入力（`https://` または `http://` から始まるもの）
4. 「保存」をクリック（URL 欄で Enter でも可）

## テストの実行

```bash
npm install
npm test
```

## 技術仕様

- **Manifest Version**: 3（Chrome 141 以上）
- **パーミッション**: `storage`, `tabs`, `sidePanel`（Web ページへのスクリプト注入はしない）
- **データ保存**: `chrome.storage.local`（アイコンは Base64 Data URL）
- **フレームワーク**: なし（純粋 JavaScript）
- **テスト**: Jest
