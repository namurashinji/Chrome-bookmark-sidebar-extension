# Custom Bookmark Sidebar

すべての HTTP/HTTPS ページの左端に常時表示されるカスタムブックマークサイドバー（Chrome 拡張機能）。

## 主な機能

- **左端固定サイドバー**（幅 50px）: ページのスクロールに関係なく常時表示
- **カスタムアイコン登録**: PNG/JPEG（最大 300KB）
- **最大 12 件のブックマーク登録**（重複 URL 不可）
- **ドラッグ&ドロップで並び替え**
- **右クリックで削除**
- **キーボードショートカット** でブックマークを開く／サイドバーを切り替え
- **表示状態の記憶**（ブラウザ再起動後も維持）

## キーボードショートカット

| ショートカット | 動作 |
|---|---|
| `` Ctrl+Shift+` `` | サイドバーの表示/非表示トグル |
| `Ctrl+Shift+A` | ブックマーク 1 番目を開く |
| `Ctrl+Shift+S` | ブックマーク 2 番目を開く |
| `Ctrl+Shift+D` | ブックマーク 3 番目を開く |
| `Ctrl+Shift+F` | ブックマーク 4 番目を開く |
| `Ctrl+Shift+G` | ブックマーク 5 番目を開く ※要手動設定 |
| `Ctrl+Shift++` | サイドバーを完全表示（不透明度 100%） |
| `Ctrl+Shift+-` | サイドバーを半透明表示（不透明度 75%） |

> ※ `Ctrl+Shift+G` は Chrome の拡張機能コマンド上限（4 つ）のため、`chrome://extensions/shortcuts` で手動設定が必要です。

## インストール（開発版）

1. このリポジトリをクローンまたはダウンロード
2. Chrome で `chrome://extensions/` にアクセス
3. 右上の「デベロッパーモード」を有効化
4. 「パッケージ化されていない拡張機能を読み込む」で本フォルダを選択
5. 任意の HTTP/HTTPS ページを開くとサイドバーが左端に表示される

## ブックマークの追加方法

1. サイドバー下部の「＋」ボタンをクリック
2. アイコン画像（PNG/JPEG、300KB 以下）をドロップまたはファイル選択
3. URL を入力（`https://` または `http://` から始まるもの）
4. 「保存」をクリック

## テストの実行

```bash
npm install
npm test
```

## 技術仕様

- **Manifest Version**: 3
- **パーミッション**: `storage`, `tabs`
- **対象ページ**: すべての HTTP/HTTPS ページ
- **データ保存**: `chrome.storage.local`（アイコンは Base64 Data URL）
- **フレームワーク**: なし（純粋 JavaScript）
- **テスト**: Jest
