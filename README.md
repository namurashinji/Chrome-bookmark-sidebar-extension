# Custom Bookmark Sidebar

すべての HTTP/HTTPS ページの左端に常時表示されるカスタムブックマークサイドバー（Chrome拡張機能）。

## 主な機能

- **左端固定サイドバー**（幅50px）：ページのスクロールに関係なく常時表示
- **カスタムアイコン登録**：PNG/JPEG（最大300KB）のアップロードに対応
- **最大12件のブックマーク登録**：重複URLは登録不可
- **ドラッグ&ドロップで並び替え**：アイコンをドラッグして順序を変更
- **右クリックで削除**：コンテキストメニューから削除
- **キーボードショートカット**：素早くブックマークを開く／サイドバーを切り替え
- **表示状態の記憶**：非表示にした状態はブラウザ再起動後も維持

## キーボードショートカット

| ショートカット | 動作 |
|---|---|
| `Ctrl+Shift+\`` | サイドバーの表示/非表示トグル |
| `Ctrl+Shift+A` | ブックマーク1番目を開く |
| `Ctrl+Shift+S` | ブックマーク2番目を開く |
| `Ctrl+Shift+D` | ブックマーク3番目を開く |
| `Ctrl+Shift+F` | ブックマーク4番目を開く |
| `Ctrl+Shift+G` | ブックマーク5番目を開く |
| `Ctrl+Shift++` | サイドバーを完全表示（不透明度100%） |
| `Ctrl+Shift+-` | サイドバーを半透明表示（不透明度75%） |

## インストール（開発版）

1. このリポジトリをクローンまたはダウンロード
2. Chrome を開き、`chrome://extensions/` にアクセス
3. 右上の「デベロッパーモード」を有効化
4. 「パッケージ化されていない拡張機能を読み込む」をクリックし、このフォルダを選択
5. 任意の HTTP/HTTPS ページを開くとサイドバーが左端に表示される

## ブックマークの追加方法

1. サイドバー下部の「＋」ボタンをクリック
2. アイコン画像（PNG/JPEG、300KB以下）をドロップ、またはファイル選択
3. URLを入力（`https://` または `http://` から始まるもの）
4. 「保存」をクリック

## ファイル構成

```
Chrome-bookmark-sidebar-extension/
├── manifest.json        # 拡張機能メタ情報（Manifest V3）
├── background.js        # サービスワーカー：タブ制御
├── sidebar.js           # コンテンツスクリプト：UI全体
├── utils.js             # 共通ユーティリティ（純粋関数）
├── style.css            # スタイル定義
├── icon.png             # 拡張機能アイコン
├── tests/               # Jest テスト
│   ├── utils.test.js
│   └── background.test.js
└── package.json         # テスト設定
```

## テストの実行

```bash
npm install
npm test
```

## 技術仕様

- **Manifest Version**: 3
- **パーミッション**: `storage`, `tabs`
- **対象ページ**: すべての HTTP/HTTPS ページ
- **データ保存**: `chrome.storage.local`（アイコンは Base64 Data URL）
- **フレームワーク**: なし（純粋JavaScript）
- **テスト**: Jest
